# Changelog

## 0.5.0
- Перейменування розділу (папка, файл, списки в головному файлі, шляхи, посилання), переставлення розділів стрілками.
- Заміна по проєкту без коментарів і `verbatim`; нормалізація всього проєкту; перевірка узгодженості позначень з уніфікацією.
- Знімки проєкту перед пакетними змінами, команда Restore snapshot.
- Доповнення й наведення для `\cite{…}` з `.bib`.
- Панель «Проблеми» (помилки, попередження, overfull з журналу збірки).
- Збірка лише вибраних `\part`.

## 0.4.4
- «New from template» створює файл у відкритій папці проєкту без діалогу «Зберегти як» (налаштування `newFromTemplateInWorkspace`).

## 0.4.3
- Екран «Початок» для папки без `.tex`, багатший `settings.json`, перевірка середовища, `build.js`.

## 0.4.0 – 0.4.2
- Живі панелі команд і розділів, шаблони-фрагменти, `\multiinclude` і групування за `\part`.

## 0.3.x і раніше
- Докладна історія змін: розділи 2.x файла `LaTeX-VSCode-setup.md`.
